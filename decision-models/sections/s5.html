Every decision model is a model you would have served anyway (run behind an API so other software can call it) plus some amount of change. The change comes in two forms: post-training, continuing to train the model's weights on new data, or a head, a small new layer trained on top of the model's hidden state that turns it into probabilities over your options without generating text. There are 6 ways to do it, ordered by how far you move from the LLM you already serve.

where Jev sits: a hosted service whose head is not public

Jev (TypeSafe) is the best-known decision model, and it is closed: you call an API and get probabilities back. What is known about its insides comes from one independent teardown of about 9,400 requests (Archer Hume, September 2026), and it splits cleanly into measured and guessed.

Measured. The shared context (the "state") is billed once however many questions you ask about it. Each question is isolated from its siblings: a secret planted in one question is invisible to another (probability 0.00), while the same secret in the shared state is found (0.90–0.92). The options inside one question do affect each other: adding a fifth option or reversing the order moves the probabilities. Asking 100 questions costs about the same latency as asking 1 (82 vs 86.5 ms). Its tokenizer matches none of 192 public ones; the closest is Qwen's. The API's confidence field is not P(correct) but the distance from a uniform guess, (pmax − 1/K) / (1 − 1/K) for K options.

Inferred, not established. A decoder backbone, probably a mixture of experts; the shared state encoded once and reused by each question branch; a final-position or pointer-style head; training with an objective TypeSafe calls RLCD (Reinforcement Learning for Calibrated Decisions), whose recipe is unpublished. So Jev does not slot cleanly into rungs 3 to 5: what is public is its interface, not its head.

DecideBench: 400 Claude-written items, 3 to 6 options each, built as 200 contrastive pairs (two near-identical items whose one differing detail changes the right answer).
