the whole mechanism in four lines
  1. Prefill: the model reads the entire conversation in one pass. Attention lets every position look at the others; the result is a KV cache and a hidden state at every position. Almost all of the cost lives here when the answer is one token.
  2. Scoring: the final layer emits logits for every token in the vocabulary, and softmax turns them into a spread summing to 1. At the answer position the spread has P(Yes) = 0.562 and P(No) = 0.438. The model has already decided how sure it is. That number exists whether or not anyone reads it.
  3. Decode: the API draws one token from the spread, shaped by temperature, and emits it as text. The draw is a coin weighted by the spread, and 0.562 is a coin that lands both ways. The text is a sample from the spread, not the spread.
  4. The readout: the API returns the logprob of each top candidate alongside the sample. Read it, and 0.562 comes back with the answer. That is all the technique is: a field you were allowed to have.
